# Notes

Evergreen notes for thinking. These are the most common writing David does - atomic notes in Obsidian that capture a single concept, evolve over time, and accumulate value through connections.

The approach draws heavily from Andy Matuschak's [evergreen notes](https://notes.andymatuschak.org/Evergreen_notes) and Luhmann's Zettelkasten. The core reframe: note-writing isn't storage, it's thinking. "Better note-taking" misses the point; what matters is better thinking.

## Evergreen note principles

These are the non-negotiables. Every note should satisfy them:

- **Atomic.** One concept per note. If you're covering two ideas, that's two notes. The test: can you write a sharp title that captures the whole thing? If the title is vague, the note is too broad.
- **Concept-oriented.** Organize by idea, not by source. Extract concepts rather than creating "Chapter 3 of Book X" summaries. This surfaces unexpected connections across domains.
- **Densely linked.** Links are the point. Create a web of ideas, not isolated documents. Link when concepts depend on, contradict, exemplify, or relate to each other. Isolated notes with zero links are red flags.
- **Associative over hierarchical.** Prefer organic connection patterns to rigid folder taxonomies. Let structure emerge from links.
- **Written for yourself.** These are personal thinking tools. Disregard external audience demands.
- **Titles are complete claims.** "Micro-pessimism paired with macro-optimism sustains ambition through cycles" not "On pessimism and optimism." The title is the API for the note - it should convey the concept without opening the note.

## Characteristics

- Tight and conversational. 2-3 sentence paragraphs.
- Tone: "me talking to you." Not SEO article, not textbook.
- Plain bullet lists when listing things. No bold, no colons, no nested formatting.
- The note should be reusable - something you can link to from multiple contexts.
- Synthesis over storage. Don't just capture information - integrate it with what you already know. Connect new ideas to existing notes, raise questions, show your thinking.

## Process adjustments for notes

The **Writing new prose** process compresses for a note. The note often starts as a thought captured in the moment, so understanding the purpose is fast: the title IS the outline, and if you can write a sharp title the note already has its shape. Research is a lighter touch — find one real example or attribution if the note makes a factual claim. When you edit, watch the claim in the title: does it actually hold, is it too broad or too narrow, could this be two notes? Notes are especially prone to sounding like they're teaching rather than thinking, so read for that. Last, ask where this links to and what existing notes it connects with.

## What to avoid in notes

- Academic formality. These are personal thinking tools.
- Exhaustive coverage. A note captures one insight, not everything about a topic.
- Transitional scaffolding. Don't write "First, let's consider..." or "Now, turning to..." Just say the things.
- Opening with context that the title already provides. If the title says it, start the body with what comes next.
- Source-indexed organization. Don't create notes named after books or articles. Extract the concepts.
- Orphan notes. If a new note doesn't link to anything, ask what's missing. It should connect to the existing web.
